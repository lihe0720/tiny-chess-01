A 4 KB chess engine in pure Python 3.13 (stdlib only): 0x88 board, alpha-beta search with iterative deepening to a fixed node budget, quiescence over captures and check evasions, transposition table, MVV-LVA + killer move ordering, and a material + piece-square evaluation. Deterministic: the same position always gets the same move.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:18080 python3 main.py
```
